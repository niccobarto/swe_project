# Document Management System - SWE Project

[cite_start]Progetto sviluppato a **Novembre 2025** per l'esame di **Ingegneria del Software** presso l'**Università degli Studi di Firenze**[cite: 16, 23].

## 📄 Descrizione
[cite_start]Il sistema consiste in un software in Java progettato per la gestione e la lettura di documenti all'interno di un archivio digitale[cite: 23]. [cite_start]Il progetto si è focalizzato sull'implementazione di una logica solida per il controllo degli accessi e sulla persistenza dei dati tramite database[cite: 23].

## ✨ Funzionalità Principali
* [cite_start]**Gestione Archivio**: Funzionalità complete per l'organizzazione e la lettura di documenti[cite: 23].
* [cite_start]**Livelli di Accesso**: Implementazione di diversi permessi e livelli di accesso per gli utenti[cite: 23].
* [cite_start]**Persistenza Dati**: Coordinazione con un database per il salvataggio strutturato delle informazioni[cite: 23].
* [cite_start]**Architettura Software**: Sviluppo basato su una solida progettazione a oggetti[cite: 36].

## 🛠️ Tecnologie Utilizzate
* [cite_start]**Linguaggio**: Java[cite: 23, 35].
* [cite_start]**Database**: SQL / Database Relazionali[cite: 23, 35].
* [cite_start]**Strumenti**: Ambiente di sviluppo IntelliJ IDEA[cite: 38].
